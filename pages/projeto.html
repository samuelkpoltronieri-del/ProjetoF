Sobre o Projeto

🎯 Objetivo

Este projeto tem como objetivo desenvolver um sistema de monitoramento ambiental em tempo real utilizando um microcontrolador ESP32, capaz de medir temperatura, umidade relativa do ar e qualidade do ar de um ambiente. Os dados coletados são publicados em um broker MQTT (Mosquitto) e exibidos em um dashboard web responsivo, permitindo o acompanhamento remoto e em tempo real das condições monitoradas.

🔧 Hardware Utilizado

O sistema é composto por um módulo ESP32, um sensor de temperatura e umidade DHT22, um sensor de gás MQ-135 para qualidade do ar e LEDs indicadores de alerta. Todos os componentes estão conectados em uma protoboard, alimentados via USB, e o firmware realiza a leitura periódica dos sensores, publicando os valores nos tópicos MQTT correspondentes.

🏗️ Arquitetura do Sistema

A arquitetura segue o modelo publish/subscribe do protocolo MQTT. O ESP32 atua como publisher, enviando os dados dos sensores para o broker Mosquitto através da porta 1883 (MQTT nativo). O dashboard web, por sua vez, atua como subscriber, conectando-se ao mesmo broker via WebSockets na porta 9001, utilizando a biblioteca Paho MQTT, e atualizando os cartões de dados em tempo real conforme novas mensagens chegam nos tópicos assinados.
